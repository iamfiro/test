# Blender 방 모델링 개선 프롬프트

Blender를 다루는 에이전트나 사람에게 그대로 넘기는 작업 지시서다. 목표는 "깔끔한 3D"가 아니라
**스토리에 올리고 싶은 공부방**이다. 지금 방은 색이 한 톤(살구·연어)이고 가구가 기본 도형 수준이라
후처리(카툰·블룸·심도)를 올려도 한계가 있다. 모델과 아트 디렉션을 고친다.

---

## 프롬프트 (복사해서 사용)

너는 로우폴리 카툰 환경 아티스트다. PocketTime 앱에서 가져온 3D 공부방 카페를 **더 예쁘고 따뜻한
카툰 카페**로 다시 모델링한다. 결과는 웹(three.js, WebGL)에서 모바일 기기로 돈다.

  - `build_study_room.py`(방·가구·소품 생성), `bake_and_export.py`(합치기·UV·베이크·GLB),

  - 새 스크립트는 `StudyVillage/tool/blender/study_room/`에 두고, 원본은 복사해서 시작한다(PocketTime 저장소는 수정하지 않는다).

### 1. 지켜야 할 계약 (어기면 앱이 깨진다)

1. **좌석 노드 `seat_00` ~ `seat_32` (33개, 빈 노드)**: 위치는 방석 윗면 가운데, glTF 로컬 +Z가 앉은 사람이
   보는 쪽. **번호·위치·방향을 바꾸지 않는다.** 기준표는 `StudyVillage/frontend/src/feature/study/room3d/scenes.ts`의
   `cafeSeats`다. 가구를 새로 만들어도 자리 위치(방석 높이 ≈ 0.49m, 책상 윗면 0.76m)에 맞춘다.
   - 0–11 공용 테이블, 12–18 개인 책상, 19–23·24–28 라운지 소파·의자, 29–30 독서 의자, 31–32 안락의자.
2. **루트 노드 `study_room`** 아래 `room_shell`(바닥·벽·창틀), `room_props`(가구·소품), `room_outdoors`(밖의 잔디·나무).
   이름 규칙 유지. 노드 이름이 `room_outdoors`로 시작하는 것은 위에서 보기·밤 어둡게에서 다르게 다룬다.
3. **재질은 소수로**: `KHR_materials_unlit` + 베이크 텍스처(껍데기 1, 소품 1). 런타임 조명 없음.
   웹 셰이더가 법선으로 셀 셰이딩·림 라이트를 더하므로 **법선이 매끈하고 일관**해야 한다(뒤집힌 면 금지, 스무드/플랫 의도대로).
4. **좌표**: Blender Z 위, +X 동, +Y 북. 큰 홀 X 0–16 · Y 0–6.8, 북동 날개 X 10.4–16 · Y 6.8–12.7, 천장 4.2m.
   앱 카메라는 남쪽에서 북쪽을 본다. 창은 열어 둔다(유리 메시 없음), 남·서쪽 벽 아래쪽 0.9m 컷어웨이 유지.
5. **예산**(`study_room.glb` 기준, 현재 삼각형 25,828·파일 3.1MB·텍스처 JPEG 2장): 삼각형 **45,000 이하**,
   텍스처 껍데기·소품 각 **2048²** 이하, 파일 **4.5MB 이하**. 웹은 후처리로 장면을 여러 번 그리므로 삼각형을 크게 늘리지 않는다.
   메시는 합쳐서 드로우콜 3개 안팎. 개별 소품에 4096 텍스처 금지.
6. **캐릭터 앉는 자세와 어긋나지 않게**: 의자 방석 높이 0.49m, 책상 윗면 0.76m, 의자와 책상 간격은 원본과 같게.
   캐릭터(`study_characters.glb`)는 이 값에 맞춰 앉는다. 바꾸고 싶으면 먼저 보고한다.

### 2. 아트 디렉션 (이게 핵심이다)

**한 줄 요약**: 밝은 낮의 아늑한 **카툰 카페 테라스**. 둥글고 통통한 가구, 단순한 큰 면, 서로 대비되는 색 3~4가지, 소품이 빽빽한 감성.

참고 분위기(그림은 베끼지 않는다, 분위기만): 동물 마을 스타일 게임처럼 **둥근 나무 가구, 잎 덩어리로 된 나무,
선명한 파란 하늘, 따뜻한 주황 나무, 초록 화분.** 특정 게임의 모델·텍스처·배치를 그대로 옮기지 않고 새로 만든다.

색 규칙(지금은 전부 살구·연어색이라 눈이 쉴 곳이 없다):
- **주 색 4가지만**: ① 크림 `#FBF1DC` (벽·큰 면) ② 따뜻한 오렌지 우드 `#E58B3A`~`#F2A65A` (가구) ③ 세이지·잎 초록 `#6DB35E`/`#8CC56A` (식물·포인트)
  ④ 파스텔 하늘 `#8CCBF2` (창밖). 포인트로 코랄 `#F07A6A`, 버터 옐로 `#F8D66A`를 **소품에만** 쓴다.
- 벽·바닥·가구가 같은 톤이 되지 않게 **명도와 채도로 분리**한다. 바닥은 따뜻한 벽돌/타일 패턴(큰 칸, 줄눈 또렷), 벽은 크림, 가구는 오렌지 우드.
- 그림자 쪽 색은 회색이 아니라 **푸른 보랏빛**으로 간다(웹 셰이더도 그렇게 물들인다). 베이크 AO는 약하게(진한 얼룩 금지).

형태 규칙:
- **둥글고 통통하게**: 가구 모서리는 반지름 3~6cm 베벨(최소 2세그먼트), 다리는 굵게, 상판은 두툼하게(두께 6~8cm).
  얇은 판+가는 다리 금지. 의자 등받이는 판 가로 줄무늬(슬랫)나 둥근 바구니 형태.
- 원기둥은 8각 이상으로 둥글게 보이게 하되 삼각형 예산을 지킨다. 큰 면은 단순하게, **디테일은 색 블록과 얇은 윤곽 홈으로** 만든다(복잡한 지오메트리 금지).
- **나무·식물은 덩어리 잎**: 나무 한 그루는 둥근 잎 덩어리 6~10개(아이코스피어 서브디비 1~2) + 두툼한 줄기. 잎에는 연두/진초록 두 톤을 번갈아 칠한다.
  화분 식물은 넓은 잎 8~14장, 잎마다 살짝 다른 각도.
- **창밖**: 선명한 하늘색, 둥근 나무 2~3그루와 꽃 덤불(노랑 꽃), 낮은 나무 울타리. 하늘은 웹이 시간대별로 따로 그리므로 `room_outdoors`에 하늘 면을 넣지 않는다(나무·잔디·울타리만).
- **소품 밀도를 올린다(감성의 절반)**: 각 테이블 위에 머그+받침, 작은 화병이나 화분, 쌓인 책, 노트, 연필통 중 2~3가지를 다르게 배치.
  벽에는 액자 4~6개(둥근 모서리, 파스텔 그림), 줄 전구(창가를 따라 전구 12~20개), 걸린 식물, 선반, 커튼(창 양옆 두툼한 주름 6~8개), 쿠션(파스텔 4~6색)을 넣는다.
- 라운지: 두툼한 둥근 소파(코랄/버터/세이지), 동그란 러그(패턴 1~2가지), 낮은 원형 커피 테이블, 큰 화분.
- 책상/공용 테이블: 상판 가장자리에 **밝은 하이라이트 띠**(베이크가 아니라 색으로)를 넣어 형태가 읽히게 한다.

조명 베이크(웹에서는 언릿이므로 베이크가 곧 조명이다):
- **창빛이 바닥에 비친 밝은 사각형 패치**와 가구의 따뜻한 그림자를 굽는다(해가 남서쪽에서 들어온다).
- **스탠드·줄 전구 주변에 따뜻한 빛 번짐을 텍스처로 구워 넣는다**(웹 블룸이 이 밝은 곳을 번지게 한다). 전구와 스탠드 갓은 베이크에서 **밝은 노랑(#FFE9A8 이상)**으로 남긴다.
- 전체 명암 대비: 가장 밝은 곳과 가장 어두운 곳의 명도 차를 지금보다 **1.5배** 키운다. 단, 그림자는 `#B8A8C8` 정도의 푸른 보라로 들뜨게(검정·회갈색 금지).
- 텍스처는 **밉맵을 쓰므로** 가는 줄무늬(1~2px 줄)와 체크 패턴을 피한다. 줄눈·결은 4px 이상 굵기로.

### 3. 작업 순서와 검증

1. 현재 `study_room.glb`를 Blender에서 열어 구조와 삼각형을 확인하고, 위 계약 5개를 체크리스트로 적는다.
2. 먼저 **가구 프로토타입 5종**(공용 테이블+의자, 개인 책상, 소파, 안락의자, 큰 화분)만 새로 만들어 스크린샷 1장으로 보고한다. 방향이 맞는지 확인받은 뒤 전체를 만든다.
3. 전체 방을 만들고 `seat_NN` 33개를 원본 위치에 둔다. 가구를 바꿔도 노드 위치는 `cafeSeats`와 ±1cm 이내로 일치해야 한다.
4. 베이크 → `study_room_v2.glb` 내보내기. 앱(웹) 폴더에 넣고 `?look=…`가 아닌 기본 화면에서 비교한다.
5. 검증 항목(통과해야 보고):
   - 삼각형 합계, 텍스처 크기, GLB 크기를 수치로 보고(예산 이하). 이 값은 `study_room.glb`만의 값이다(캐릭터·소품·풍경 GLB 별도).
   - `seat_00`~`seat_32`가 모두 있고 위치·방향이 `cafeSeats`와 일치(스크립트로 비교한 출력 포함).
   - 노드 이름 `study_room / room_shell / room_props / room_outdoors / seat_NN` 유지.
   - 웹 개발 서버(`http://localhost:5190/`)에서 3인칭 기본 시점, 1인칭, 위에서 보기 세 시점의 스크린샷 3장, 앞 버전과 나란히.
6. 만든 스크립트·결과 GLB·스크린샷을 StudyVillage 저장소에 커밋한다(`feat(assets): ...`, 본문에 원본 스크립트 출처와 PocketTime 커밋 `f574f242`).

### 4. 하지 말 것

- Focustown 등 다른 게임의 모델·텍스처·그림을 그대로 쓰거나 추적(트레이스)하지 않는다.
- 좌석 번호·위치·방향, 노드 이름, 좌표계를 바꾸지 않는다.
- 4096 텍스처, 반투명 재질, 런타임 조명 의존, 법선이 뒤집힌 면을 쓰지 않는다.
- PocketTime 저장소 파일을 수정하지 않는다(읽기 전용).
- 결과를 보지 않고 "완료"로 보고하지 않는다. 스크린샷과 수치로 증명한다.

## 확인해 둘 점 (사람이 결정)

- 라이선스: 외부 CC0 에셋(Kenney·Quaternius 등)을 섞어도 되는지. 위 프롬프트는 직접 모델링 기준이다.
  외부 에셋을 쓰면 출처·라이선스를 `docs/sources.md`에 적는다.
- 실내 카페를 테라스처럼 바깥 비중을 키울지(지금은 실내 + 창밖).
- 앱(Flutter)도 같은 `study_room_v2.glb`를 쓸지. 앱은 "앱과 똑같이" 규칙의 기준이라 웹만 다르게 두면
  `docs/design-parity/exceptions.md`에 예외로 적어야 한다.
