- **통계 연속 공부 불꽃**: 앱 `StreakFlame`의 씨앗 불씨·시계 바늘 회전은 웹에서 뺐고 점토 불꽃 모양과 몸통 눌림·늘어남만 CSS로 둔다(`stats/StreakFlame.tsx`). 이유: 앱은 Canvas 커스텀 페인터이고 웹은 정적 SVG로 같은 모양을 옮겼다. 2026-11-23 사용자 요청으로 통계 화면을 앱 캡처에 맞춰 구현했다.
- **사운드 패널 자동 재생**: 앱은 공부방에 들어오면 마지막 소리를 바로 튼다. 웹은 페이지를 연 뒤 공부 탭에 처음 들어올 때 한 번 시도하고, 브라우저가 자동 재생을 막으면(사용자가 아직 화면을 누르지 않음) 오류 없이 멈춘 채로 두어 턴테이블을 눌러 틀게 한다. 설정은 앱처럼 기기에만 둔다(localStorage `study.sound.v1`). 앱의 상점 음반(다운로드)은 아직 없다.
- **채팅 시트**: 앱 캡처의 크림 시트(위 안내 한 줄·회색 말풍선) 대신 사운드 패널과 같은 햇살 노랑 틀, 머리 없음(연결 중·끊김만 목록 위 알약), 남의 말은 이름 첫 글자 동그라미·흰 말풍선, 내 말은 햇살 노랑, 이어 쓴 말은 이름·시간을 한 번만, 넓은 화면 최대 520. 사용자 결정(2026-11-23).
- **미니 타이머 크기**: 앱 높이 60·과목 카드 최대 260·시간 24·재생 46을 웹에서 72·320·32·56으로 키웠고, 과목 고르기 아이콘을 동그란 칩에 넣었으며, 일시정지 중엔 시간을 흐리게 한다. 넓은 화면(700 이상)은 오버레이 칸을 600까지 넓혀 다 들어가게 했다. 사용자 결정(2026-11-23).
- **집중 모드(PC·웹)**: 원본 가로 화면은 시간을 사람 왼쪽, 단추를 오른쪽에 둔다. 웹은 가로이면서 폭 768·높이 500 이상인 창에서 원본처럼 시간은 왼쪽·단추는 오른쪽 양끝에 두되 화면 세로 가운데에 크게(시간 104·단추 96) 둔다. 세로 화면은 원본 자리에 두되 시간 48·단추 80으로 키웠다. 세션이 없으면 끝내기 단추를 숨긴다(원본은 흐리게 둠). 사용자 결정(2026-11-23).
