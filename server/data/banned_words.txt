# 금칙어 목록: 닉네임·채팅·방 이름 공통(server/src/moderation/banned-words.ts).
# 한 줄에 한 단어. '#'로 시작하는 줄과 빈 줄은 무시한다.
# 비교 방법: 입력과 이 단어를 똑같이 정규화(NFKC → 소문자 → 글자·숫자가 아닌 것 모두 제거)한 뒤
# 입력 안에 단어가 들어 있으면 거절한다. 그래서 "씨 발", "f.u.c.k", 전각 "ＦＵＣＫ"도 걸린다.
# 포함 검사라 짧거나 흔한 글자 조합을 넣으면 멀쩡한 말이 걸린다("미친듯이", "보지 마", "grape"의 rape,
# "analysis"의 anal 등). 그런 말은 일부러 넣지 않았다. 무작위 닉네임 조합이 걸리지 않는지는 테스트가 확인한다.
